> **الإصدار:** TASK-GATE v2.0
> **الحالة:** ACTIVE / REQUIRED AGENT GATE
> **الغرض:** حفظ قائمة العمل المفتوحة وخطة التنفيذ الكاملة بحيث يمكن لأي وكيل استئناف العمل من الحالة الفعلية دون فقدان المهام أو اختراع مهام جديدة.
> **مصدر الحقيقة التشغيلي:** `main` + `PROJECTS.md` + هذه الوثيقة + العقود الحاكمة + Fresh Exact-SHA Evidence.
> **ممنوع اعتبار أي SHA أو Evidence تاريخي دليلًا للحالة الحالية دون إعادة التحقق.**

## 0. قاعدة الدخول الإلزامية

```text
PROJECTS.md → المهام.md → AGENTS.md → RESOLVE EXACT main SHA → IDENTIFY ACTIVE TASK → READ AUTHORITATIVE CONTRACT → RCA / SCOPE LOCK → MAIN-FIRST CHANGE WHEN ELIGIBLE → TARGETED REGRESSION → EXACT-SHA PROOF → UPDATE MAPS
```

## 1. مبادئ الالتزام

`main` هو مصدر الحقيقة الحالي. `ACTIVE` فقط قابل للتنفيذ. `LOCKED` dependency-gated. `CANDIDATE ≠ ACTIVE`. `DEFER ≠ forgotten`. `UNKNOWN ≠ PASS`. `INCOMPLETE ≠ SUCCESS`.

لا تعطيل اختبارات، ولا تخفيف assertions، ولا حذف coverage، ولا تجاوز authorization/policy/approval/evidence. لا LLM-direct production execution. لا duplicate registry/validator/truth store/execution owner بلا حاجة مثبتة.

كل failure يحتاج RCA، وكل إغلاق يحتاج targeted regression + affected graph + fresh exact-SHA evidence.

## 2. حفظ المهام

Open Task Queue يجب أن يحتفظ بالـID والعنوان والحالة والمالك والنطاق والاعتماد والعقد وRCA/invariant والاختبار ومعايير الخروج والدليل الحالي والخطوة التالية والـblocker.

حذف مهمة ممنوع قبل:

```text
MERGED TO MAIN
∧ EXACT MAIN SHA CONFIRMED
∧ TARGETED TESTS PASS
∧ REQUIRED CI / CERTIFICATION PASS
∧ TASK INVARIANT PROVEN
∧ NO DEPENDENT REPAIR OPEN
∧ CLOSURE EVIDENCE RECORDED
∧ PROJECTS.md CLOSED HISTORY UPDATED
∧ NEXT TASK / DEPENDENCIES UPDATED
```

## 8. RCA rule

```text
trigger → propagation path → violated invariant → responsible source → observable symptom
```

Closure:

```text
mechanism proven
→ causal source repaired
→ targeted regression passes
→ affected graph passes
→ fresh Exact-SHA evidence
```

## 9. MAIN-FIRST protocol

Bounded routine work may execute directly on `main` when:

```text
single owner ∧ bounded scope ∧ targeted regression available ∧ no unresolved RCA dependency ∧ no unauthorized production mutation
```

Use `execution` only for materially risky, broad, conflict-prone, production-sensitive, architectural, or isolation-required work. MAIN-FIRST never weakens testing, evidence, security, approval, rollback, or certification requirements.
