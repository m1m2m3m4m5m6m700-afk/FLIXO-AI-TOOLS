# FLIXO Public Claims Allowlist

Public launch messaging may claim only the six canonical executable MVP capabilities:

- background-remover
- image-upscaler
- image-cropper
- image-compressor
- image-converter
- image-effects

Descriptions must remain factual:
- Background Remover: remove connected, uniform backgrounds locally.
- Image Upscaler: increase image dimensions with bounded browser processing.
- Image Cropper: crop and resize images for exact dimensions.
- Image Compressor: reduce supported image file size in the browser.
- Image Converter: convert supported raster image formats locally.
- Image Effects: apply bounded brightness, contrast, saturation, and grayscale adjustments.

Other registry entries may be recognized, planned, unavailable, or non-MVP. Their presence in the registry is not launch authorization.

Do not advertise OCR, Pix Studio, object removal, watermark removal, video tools, image generation, or other non-MVP capabilities as part of the certified launch unless a later exact-SHA scope decision explicitly promotes them.
