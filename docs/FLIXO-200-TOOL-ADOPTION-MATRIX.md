## Admission requirements

Every candidate requires a canonical registry entry, schema, executor, verifier, recovery policy, localized UI, browser-local execution evidence, no-upload evidence, compatibility/performance tests, and dependency/license review. Tools requiring cloud inference or remote file processing do not count toward the strict 200 browser-local tools unless a verified local implementation is provided.
