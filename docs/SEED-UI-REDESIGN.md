# Seed Premium UI Redesign

The Seed editor received a visual-only premium presentation layer.

## Scope
- Editorial dark canvas workspace with stronger depth and hierarchy.
- Premium sticky editor header with clearer action hierarchy.
- More immersive canvas surface and image focus treatment.
- Refined control-sidebar surface and scroll treatment.
- Responsive behavior for tablet/mobile widths.
- Reduced-motion-safe transitions.

## Safety
- Seed WebGL engine unchanged.
- Editing state and history unchanged.
- Existing accessibility roles, labels and test selectors unchanged.
- No provider/deployment dependency.
