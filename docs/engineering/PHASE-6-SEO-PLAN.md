# Phase 6 — SEO Certification Scope

Baseline: `main` at the start of Phase 6.

## P6-A

Certify canonical localized URLs, 20 locale hreflang targets, self-reference symmetry, x-default, origin consistency, and structured-data URL parity.

The certification must derive locale language tags from `LOCALE_METADATA` and localized paths from the existing SEO/routing helpers.

## P6-B

After P6-A is green and merged, certify prerendered HTML with a real DOM parser and prove runtime/prerender parity.

No AdSense or performance work belongs in P6-A.
