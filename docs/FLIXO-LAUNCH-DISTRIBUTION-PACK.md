# FLIXO Launch Distribution Pack

All launch copy is subordinate to the verified candidate capability set.

## Core message

FLIXO is a browser-first AI creative toolbox for fast image and visual editing. The product combines natural-language agent guidance with direct manual tools while keeping browser-local file handling as a core privacy boundary.

## Product Hunt

Use a concise maker-led description, a short demo, verified screenshots, and a transparent list of current capabilities and limitations. Do not ask users to manipulate ranking or voting.

## Hacker News

Technical angle:
- browser-first editing architecture
- deterministic capability registry and execution boundary
- agent confirmation and verification
- exact-SHA release discipline
- privacy boundary and known limitations

## Reddit

Post only where the community rules permit product/project sharing. Lead with the problem, implementation, evidence, and lessons. Avoid generic promotional spam.

## X / LinkedIn

Prepare separate posts for:
1. Launch
2. 30–40 second product demo
3. Architecture / agent execution boundary
4. Privacy and browser-local processing
5. Open-source engineering / release evidence

## YouTube

Required videos:
- What is FLIXO?
- Full editor/agent demo
- Agent vs Manual workflow
- Browser/local privacy architecture
- Security and release verification

## Email

Prepare:
- launch announcement
- feature walkthrough
- release notes
- incident/status updates

No channel may advertise a capability that is not executable and verified in the release candidate.
