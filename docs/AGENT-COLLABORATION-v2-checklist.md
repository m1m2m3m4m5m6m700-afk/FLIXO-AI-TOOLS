# Collaboration Gate Checklist

CHECK_IN: active claim + exact SHA + disjoint scope
HEARTBEAT: unchanged branch/SHA before lease expiry
RE_INGEST: mandatory after SHA or base-state change
COLLISION: path/contract/Root Cause overlap fails closed
HANDOFF: explicit outgoing and incoming phases
VERIFY: fresh evidence bound to exact SHA
CHECK_OUT: release write authority
CERTIFY: Full Matrix only
