# HISTORICAL ACTION AGENT ACTIVITY

The historical Action corpus is also the long-term experience layer for the resident Action agents.

Red-session activity is provisional. After targeted verification, exact-SHA confirmation, and Canonical GREEN, the proven activity is promoted under `docs/agents/historical-action-errors/agent-activity/`.

Every promoted record binds:
- taskId
- failureFingerprint
- targetSha
- failedRunId
- agentId/lane
- RCA/hypotheses
- challenges
- repair strategy
- targeted regression
- exact-SHA evidence
- final solution
- lesson / anti-lesson
- provenance

Historical activity never grants mutation or certification authority.
