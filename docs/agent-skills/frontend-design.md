# FLIXO Frontend Design Skill

## Purpose
Keep FLIXO Agent Studio and tool surfaces visually intentional while preserving function.

## Review dimensions
- Clear hierarchy for prompt, plan, progress, verification, and result states.
- Consistent spacing, typography, borders, and state semantics.
- Responsive behavior across desktop and mobile.
- Correct RTL/LTR mirroring for localized surfaces.
- Keyboard focus, accessible labels, live regions, and disabled/loading states.
- Avoid arbitrary redesigns when a targeted correction is sufficient.

## Proof
Design changes require existing accessibility/runtime tests plus a visual or DOM-level regression check when the behavior is user-visible.
